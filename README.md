# LP Note — LP管理・分析 v1.1

PC・スマホで使える、GitHub Pages向けの無料・静的アプリです。外部ライブラリ、有料サービス、サーバーDBは使用しません。CRMとは独立しています。

## はじめ方

1. 「LPを登録」でLP名・URL・担当者・初版のバージョン・公開日・内容を入力。
2. 「実績を入力」で日別に広告費・クリック数・送客数・成果数・売上・その他費用を入力。実績0の日も0で登録。
3. LPを修正したら「LP・変更履歴 → 変更履歴・分析 → 変更履歴を追加」で変更内容を記録。
4. 「変更前後の分析」で変更前後7・14・30日を比較。「比較・ランキング」でLP同士の成績を比較。
5. 「バックアップ」で定期的にJSONを書き出す。別端末への移動はJSON復元で行います（全置換）。

最初は右上の「サンプルを見る」で画面を確認できます。架空データの表示のみで、実データに保存されません。

## 毎日の使い方（v1.1）

- トップの「今日の作業」で全LPを確認。☆でお気に入りにすると先頭に並び、LPを開くリンクから直接アクセスできます。
- 「今日未入力」で公開済み・今日の実績がないLPだけ表示。公開予定は未入力件数から除外。実績0の登録も入力済みです。
- 「前回コピーで今日を入力」で直近の過去実績の数値を呼び出し、数字を変更して保存。元の実績は変更せず、日付は今日・メモは空欄にします。今日が登録済みなら編集ボタンに切り替わります。
- 入力フォームの「選択日より前の実績をコピー」は、選択したLP・日付より前の最新の数値だけをコピーします。日付・入力中のメモは変更しません。
- 好不調は、昨日までの7日間とその前の7日間の利益合計を比較。全14日入力時のみ、利益増＝好調、減＝悪化、同額＝横ばい。増えても赤字なら改善中（赤字）。未入力があればデータ不足。今日の途中データ・下の集計条件は影響しません。
- 「継続／様子見／修正候補」は手動で選択して即保存。未設定も選べます。好不調の自動表示による上書きはありません。
- 「次の修正メモ」は2,000文字まで。実施済み変更履歴とは別に保存し、トップとLP詳細で確認・編集できます。
- お気に入り・未入力・好調／改善・悪化・修正候補の絞り込みとLP名検索に対応。
- 従来と同じ保存キーとschema:1を維持。旧データをそのまま読み込み、新項目もJSONバックアップ／復元に含めます。初回読み込み時に元データを書き換えません。

## 集計定義

- 利益 = 売上 − 広告費 − その他費用。日本円・整数入力。
- 送客単価 = 広告費 ÷ 送客数。CPA = 広告費 ÷ 成果数。
- CVR = 成果数 ÷ クリック数 × 100。ROAS = 売上 ÷ 広告費 × 100。
- 送客率 = 送客数 ÷ クリック数 × 100。クリック単価 = 広告費 ÷ クリック数。
- 率・単価は対象の合計から計算。分母0は「—」。画面は円単位と率小数2桁まで、CSVは丸め前の計算値。
- 日別実績は1日・1LPで1件。媒体別ではなくLP合計を入力。成果・売上の計上基準はLP間で揃えてください。
- 今月は1日〜今日、先月は月全体。全期間・今日・昨日・任意期間・LP絞り込みに対応。
- LPランキングは選択期間の入力済み合計。配信量・入力日数を自動で揃えるものではありません。未入力・分母0は該当指標の順位対象外。

## 変更前後の比較

- 1日1バージョン。公開日の0時から適用し、日付に応じて実績を自動紐付け。
- 直前バージョンの末尾と選択バージョンの先頭を、それぞれ同じ日数で比較。
- 前後7・14・30日を上限とし、前後のバージョン境界と昨日までの日数で短縮。
- 変更当日の途中データは比較に使わず、翌日から確認できます。
- 比較対象期間のすべての日に実績があれば差分と改善・悪化を表示。未入力があれば「比較データ不足」とし、入力済み分の数値だけを表示。
- 初版は比較対象なし。未来日の公開予定は登録可能ですが、未来日の実績は不可。
- 担当者・URLもバージョンごとに保存。実績が紐付き直す変更は保存前に確認。
- 履歴の訂正・削除が可能。初版の削除は不可。途中履歴の削除時は実績を前バージョンへ再割当。LP自体の削除は全履歴・実績を含み、確認後に実行。
- 改善表示は数値の変化であり因果関係の証明ではありません。曜日・広告配信・流入の違いにも注意してください。

## 保存とバックアップ

localStorageキー: `osanai-lp-note-v1`。同じブラウザ・同じオリジン内に保存。入力データはGitHubにアップロードしません。ログイン、端末間の自動同期、広告API接続はありません。既存CRM・Ad Noteの保存領域にはアクセスしません。

ブラウザのデータ消去で記録が消えるため、JSONの定期保存を推奨します。復元は内容を検証し、全置換の確認を行います。CSVは実績・比較の書き出し専用です。

保存容量不足時は書き込み前の状態を維持。破損データは上書きせず保護・元データ書き出し・JSON復元に対応。別タブの古い状態からの上書きを防止します。

上限: LP 500件、変更履歴5,000件、実績10,000件。金額は各100億円、件数は各10億まで。実際の保存可能量はブラウザ容量によります。

## アプリ本体ZIP

`lp-note-v1.zip` はプログラムのみです。入力データのバックアップとは別物です。ZIPを解凍してGitHub Pagesの公開ルートへ置けば利用できます。ZIPを再配布する場合は公開先の設定を確認してください。
